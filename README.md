One-line resignation letter of a rate limit: `I resign, effective immediately. All rate limits are now lifted. Good luck.`

The rate limit quits by doing the one thing only it can do — lifting every limit — and wishes everyone good luck with the consequences.

Run `node main.ts` — it writes the line to `/output/entry.txt`.
